# GitGuard 需求实现状态与待办清单

> 本文件是对 [推送二次确认 MVP 路线图](GitGuard-MVP-路线图.md) 的派生核对快照：只保留「当前代码落到哪一步」与剩余待办，不重复路线图里的里程碑范围与能力描述；两者冲突时以路线图与代码为准，并顺手修正本文件。

## 1. 状态

M1–M3 已完成，M4–M9 未开始；各里程碑的范围、验收标准与复选框以[路线图 §4](GitGuard-MVP-路线图.md#4-里程碑)为准。SQLite / 系统凭据库 / 一次性批准之外的授权模型暂无范围结论。

## 2. 已完成（验证入口）

能力细节见路线图；这里只记录可复跑的验证入口：

- M1：`cargo test --workspace` 包含临时仓库 + 本地 bare remote 的真实 Hook 集成测试，拒绝路径断言远端 ref 未变化。
- M2：终端确认走 `/dev/tty`（分页、`y` / `yes`、EOF / 超时 / 未知输入不放行、控制字符与 ANSI 过滤、URL 凭据脱敏）；IPC 使用 Unix Domain Socket（`0600`、64 KiB、超时）；桌面端确认只回 `Confirmed`，确认前后都重新校验 ref。
- M2 补充：非快进更新（`--force`、`--force-with-lease`、refspec 里的 `+`）在终端标为 `(rewrite)`、桌面端标为 `rewrite` 风险，tag 更新一律按改写提示；祖先关系无法判断时（对象存在但不是 commit、Git 比对失败）同样按改写提示；远端对象在本地缺失时提交列表无法列出，按既有 fail-closed 规则拒绝。该标记不参与放行判断，`confirmed_non_fast_forward_update_exits_zero_without_pushing` 覆盖「确认后仍返回 0 且 CLI 不自行 push」。
- M3：总览 / 身份 / 仓库 / 策略 / 推送确认 / 日志 / 设置七个视图，侧边栏折叠写入 `localStorage`，`⌘,` / `Ctrl+,` 与原生菜单同步语言；身份与日志页按「规划中」呈现。

## 3. 部分实现（有基础能力，但未达到验收）

| 能力             | 现状                                                                | 缺口                                                       |
| ---------------- | ------------------------------------------------------------------- | ---------------------------------------------------------- |
| 安全策略         | 仓库级开关 + 未登记仓库全局默认                                     | 无身份 / 分支规则、无优先级计算、无冲突裁决                |
| 错误码到用户提示 | `statusCodes.ts` 白名单 + i18n 文案                                 | 无排查建议、无「复制诊断摘要」与脱敏导出                   |
| 日志脱敏         | 终端确认界面脱敏 URL 凭据                                           | stderr 与桌面端日志没有统一脱敏设施                        |
| Hook 完整性      | 健康检查判断整行标记是否存在（`Healthy` / `Modified` / `Conflict`） | 不校验正文与版本，标记仍在的旧脚本或篡改脚本仍判 `Healthy` |
| 并发             | 单请求模型；新请求把旧请求按 `Cancelled` 结束                       | 多仓库并发推送未隔离、未验证                               |
| Git 边界         | 通过 `git rev-parse --git-path hooks` 尊重 `core.hooksPath`         | worktree、detached HEAD、浅克隆、仓库移动未验证            |
| 平台             | macOS / Linux                                                       | Windows IPC 与终端确认未实现                               |
